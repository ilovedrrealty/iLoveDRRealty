# Dominican Republic resource library

The owner requested useful entries from their existing [Dominican Republic resource directory](https://docs.google.com/spreadsheets/d/1eEeugKpelLliE_Yt31OypdMDJOjMk0Pgeph7ktRJGIw/edit). The 2026-10-18 review read the master directory's 299 entries and the Read Me, Due Diligence and Calculators tabs, selecting 27 resources: 22 public and 5 specialist links. Four public credential/ownership sources were added to the recommended catalog on 2026-10-20, bringing it to 31 entries (26 public, 5 specialist). Catalog entries become live only after an Admin imports and publishes the content version.

## Access and administration

Public visitors use Resources → Resources & articles (`/blog/#website-resources-heading`). Resources → DR Professionals (`/professionals/`) explains the network and signup; professional search and contacts require an active, verified login at dashboard `/professional-directory`. Every dashboard workspace has Resources with the public link library, buying guide, ROI calculator, member directory and professional-profile entry points.

The dashboard has working `/buyer-tools`, `/owner-tools` and `/realtor-tools` hubs with labeled action cards and short instructions. Buyer tools are shared; Owner and Realtor hubs require the corresponding account role or Admin access. Admin workspace switches preserve the actual Admin identity and server permissions. Full hubs include the area converter and temporary printable property-review checklist. Realtors and Admins can open `/research` for GIS, title and official sources, including the existing 8 official links and 5 additional technical resources. A professional-directory service category never grants access to these account workspaces.

Admin Website Editor → Resources & tools → Add missing recommended resources imports only absent entries into the draft. Existing IDs/URLs, descriptions, access choices and disabled entries are preserved. The collection respects the 100-tool limit. Nothing is published until the Admin publishes the content version. The existing version history provides content rollback.

Public reads use `/site/settings`; the server removes restricted tools, and the client filters restricted/disabled/unsafe links again. Resource imports copy links and explanatory text, not provider contacts, business profiles, login credentials or property files. Professional-profile imports are a separate private-draft workflow; consent and Admin approval are required before a profile appears in member search.

## Source review

HTTP reachability and official page identity were checked on2026-10-18. The ITADO `/miembros-activos/` link returned404 and was replaced with `/consulta-de-miembros/`; the old DGII IPI page also returned404 and was replaced with the current official DGII page. The Ministry of Environment service link redirects to its current catalog. The insurance regulator redirects to `sis.gob.do`. SIGEO failedDNS and the ONE map's TLS chain could not be verified; neither was imported. No certificate validation was disabled.

The four 2026-10-20 additions carry dated official-source evidence in `RECOMMENDED_DR_SOURCE_EVIDENCE`. Evidence applies to the reviewed URL; an Admin's replacement destination does not inherit that verification label.

These links open the provider's portal in a new tab. Account, document, fee or professional requirements remain with the official service. A parcel map does not establish title; a member lookup or RNC record does not endorse an individual. No mortgage rate, approval, tax exemption or public-service coverage is promised.
