# Dominican Republic resource library

The owner requested useful entries from their existing [Dominican Republic resource directory](https://docs.google.com/spreadsheets/d/1eEeugKpelLliE_Yt31OypdMDJOjMk0Pgeph7ktRJGIw/edit). The 2026-10-18 review read the master directory's299 entries and the Read Me, Due Diligence and Calculators tabs.27 resources were selected:22 public and5 specialist links.

## Access and administration

Public visitors use Resources → Resources & articles (`/blog/#website-resources-heading`). Every dashboard workspace has Resources, with the same public library and working buying-guide, ROI and professional-directory links. Realtors and Admins also have Research tools (`/research`) with the existing8 official links, area converter, temporary printable property-review checklist and the5 additional technical resources.

Admin Website Editor → Resources & tools → Add missing recommended resources imports only absent entries into the draft. Existing IDs/URLs, descriptions, access choices and disabled entries are preserved. The collection respects the100-tool limit. Nothing is published until the Admin publishes the content version. The existing version history provides content rollback.

Public reads use `/site/settings`; the server removes restricted tools, and the client filters restricted/disabled/unsafe links again. No private provider contacts, business profiles, login credentials or property files are imported from the sheet. Professional-directory profiles still require consent and approval.

SIGEO failedDNS and the ONE map's TLS chain could not be verified; neither was imported. No certificate validation was disabled.

These links open the provider's portal in a new tab. Account, document, fee or professional requirements remain with the official service. A parcel map does not establish title; a member lookup or RNC record does not endorse an individual. No mortgage rate, approval, tax exemption or public-service coverage is promised.
